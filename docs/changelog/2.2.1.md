Версия **TeleCart 2.2.1**

Обновление связано с актуализацией сторонних библиотек, используемых модулем. Эксплуатации данных уязвимостей в самом коде TeleCart не зафиксировано.

## Инструкция по обновлению

1. Установите новую версию через админ-панель OpenCart (старую удалять не нужно — устанавливать поверх). 
2. Обязательно зайдите в настройки TeleCart модуля, чтобы завершить настройку модуля после установки.
